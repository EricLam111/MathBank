# 数学分析刷题台（MathBank）

一个纯本地的题库 + 课程应用：给题 → 判分 → 逐步讲解 → 标注知识点 → 反查回课程。

**不需要服务器、不需要联网、不需要安装任何依赖。** 双击 `index.html` 就能用。

---

## 怎么用

打开 `index.html`，然后：

| 页面 | 作用 |
|---|---|
| 首页 | 进度总览 + 「今天从这里开始」推荐（优先错题多的板块，其次没做过的板块） |
| 课程（点板块卡进入） | 每个知识板块 3 讲，每讲是逐步讲解 → 例题 → 常见陷阱 → **这一讲的配套练习** |
| 练习 | 逐题作答，答完立刻给判定 + 标准答案 + 逐步解答 + 为什么考这个 + 容易错在哪 |
| 题库 | 63 道题全列表，按板块筛选，每题带知识点/难度/题型标签 |
| 错题本 | 做错过且还没连对两次的题；点「全部重做」一次性刷掉 |
| 统计 | 按板块、按知识点的正确率与掌握数；可一键清空进度 |
| 看懂（3D） | 九个互动场景：拖动旋转、缩放、调整参数，阅读解释并跳转相关题目 |
| 背单词 | 自己贴单词进词库，然后**看着单词照着打**，所有词一轮轮循环重复；缺中文的词自动补上（内置数学词表优先，查不到再联网翻译） |

**键盘**：输入框里按 `Enter` 检查答案；答案已判定时按 `Enter` 进下一题。
**进度**存在浏览器 `localStorage`（键 `mathbank.progress.v1`），换浏览器或清缓存就没了。

## 内容规模

- **7 个知识板块 / 21 讲**：数列极限、函数极限与连续、导数与微分、中值定理与泰勒、定积分与反常积分、级数、反例博物馆。
- **63 道题**：36 道计算/填空、22 道选择、5 道证明（证明题对照解答自评）。其中 24 道改编自北邮《大邮数学集》历年数学分析真题（答案重算核对，逐步解答为本项目重写）。

每题都带：知识点 `kp`、难度 1–3、3–5 步的逐步解答、`why`（为什么考这个）、`trap`（最容易错在哪）、1–2 条提示。

---

## 判分是怎么做的

选择题点选；证明题对照解答后自评；**计算题用自己写的表达式解析器判等价**（不用 `eval`）：

| 你输入 | 判定 |
|---|---|
| `1/2`、`0.5`、`2/4` | 都可以（数值容差 1e-3，相对） |
| `sqrt(3)/3`、`1/√3`、`1/sqrt(3)` | 都可以 |
| `π²/6`、`pi^2/6`、`pi^(2)/6` | 都可以 |
| `e`、`2.718281828` | 都可以 |
| `(e-1)/2`、`0.859` | 都可以 |
| `e^-1`、`1/e` | 都可以 |
| `发散`、`不存在` | 走 `accept` 文字等价列表 |

支持的写法：`+ - * / ^`（或 `**`）、括号、隐式乘法（`2pi`、`3(1+2)`）、
函数 `sqrt abs exp ln log sin cos tan asin acos atan sinh cosh tanh floor ceil round`、
常数 `pi e`、上标字符 `x²`、根号 `√3`、全角括号与全角数字。

> 解析不了时会明确告诉你「解析器说：……」，而不是默默判错。

## 加题 / 加课

题库是纯数据，改 `data/questions.js` 即可。一题的最小结构：

```js
{
  id: 'q8-1',                    // 唯一
  topic: 't1', section: 's2',    // 必须对上 lessons.js 里的板块 id 与讲 id
  kp: '重要极限 e',               // 知识点标签（统计页按它聚合）
  difficulty: 1,                 // 1 基础 / 2 进阶 / 3 难点
  type: 'numeric',               // numeric | choice | self
  prompt: '求 $\\lim_{n\\to\\infty}(1+\\frac1n)^n$。',
  value: 'e',                    // numeric 的标准答案，可写表达式
  accept: ['e', '自然常数e'],     // 可选的文字等价写法
  ans: '$e$',                    // 判完后展示的标准答案（LaTeX）
  hints: ['…'],
  steps: ['第一步…', '第二步…', '第三步…'],
  why: '这道题在考什么',
  trap: '最容易错在哪'
}
```

- `choice` 用 `choices: [...]` + `answer: 索引`（索引从 0 开始，字母自动生成 A/B/C/D）。
- `self` 不需要 `value`，判分方式是「看解答 → 我独立做对了 / 做错了」。
- 数学统一写在 `$...$` 里（`$$...$$` 是独立成行公式），由本地 KaTeX 渲染。
- **字符串里的 LaTeX 反斜杠要写两个**：`'$\\frac12$'`。

课程在 `data/lessons.js`，每讲的结构是 `{ id, title, steps: [...], example: {title, body}, pitfalls: [...] }`。
只要题目的 `topic` + `section` 对得上，课程页底部就会自动出现「这一讲的配套练习」和「连做这一讲的 N 题」按钮——课程与题库不需要手工维护链接。

## 已验证的事
- 单词台（照着打）：空词库引导、载入 20 个示例词、批量添加（`word`／`word 中文`／`word,中文`）、大小写不敏感去重、删除、`Enter` 直接添加 / `Shift+Enter` 换行都实测通过；题面确实把单词本身显示出来（46px 等宽字体）；照着打对 → 打对次数 +1 并自动进下一题；打错 → 逐字母标红（`sequence` 打错末位，8 个字母里恰好 1 个 miss）、输入框清空可立刻重打、**不计入打对**；大小写不敏感；跳过会换词并把该词放回队尾；打对 5 次标记「已打熟」（5 颗点全亮），「只练没打熟的」模式下不再抽到它；轮次自动推进（3 个词时连答 12 次推进到第 7 轮）。
- 自动中文释义：加词后自动补全（同一批实测：`derivative` → 「导数」走内置词表、`serendipity` → 「意外发现」、`perpendicular` → 「垂直」走在线翻译）；翻译结果写回 `localStorage` 缓存，第二次打开不再联网；题面上中文与单词并排显示并带来源标记；把 `fetch` 打断模拟断网 → 词条标「未查到」且状态提示可手填，恢复网络后点「补全缺失的中文」重试成功（`obfuscate` → 「隐身术」）；内置词表 223 条、无重复键、全含中文。
- 单词台持久化：`localStorage` 写入含 `streak`/`attempts` 等统计字段；测试数据已清空，你打开是干净状态。

- 4 个 JS 文件语法检查通过（`node --check`）。
- 数据完整性：id 不重复；每题 `topic`/`section` 都能对上课程；每题至少 3 步解答；选择题答案索引合法；标准答案表达式全部可求值；**21 讲每一讲都有配套题**。
- 判分引擎：36 道数值题的正确写法全部判对、错误答案全部判错、`accept` 列表全部判对；22 道选择题正确选项判对、其余判错。
- 交互：练习启动、正确答案、错误答案 +「再试一次」、提示、跳过看解答、证明题自评、下一题、进度写入 `localStorage`、错题本规则（连对两次才移出）、统计聚合、题库筛选全部通过。
- 全站 73 个页面（首页 + 7 讲 + 63 题 + 题库/统计）在窄视口下无横向溢出、无公式渲染错误、无 JS 运行时异常。
- 3D 页面：九个场景已检查画布输出与滑块读数变化，缩放与重置按钮已验证。
- 3D 读数抽查：ε=0.3 时 N=14（与 q1-2 的答案一致）、ξ=1/√3 时判定「切线平行于割线」、n=128 时黎曼和误差 < 0.005、1/n² 前 40 项和 = 1.6202、|x| 的左右斜率恒为 ∓1。
- 入口打通：导航「看懂（3D）」、首页推荐卡「看 3D」、题目卡与解答里的「看 3D 演示」、课程每一讲标题下的入口；板块级回退标注「（本板块）」。

## 没做的事（明确边界）
- 单词台没有云同步和发音：词库与统计只在本机 `localStorage`（键 `mathbank.words.v1`），导出 JSON 可以自己备份。

- 证明题**不做自动判分**：机器判数学证明不可靠，改成「对照标准解答自评」，诚实且不会骗你。
- 没有云同步、没有账号、没有间隔重复算法（只有「连对两次算掌握」和错题本）。
- 只覆盖单变量数学分析；多元微积分、复分析、实分析没进来。
- 3D 讲解包含九个互动场景；「反例博物馆」尚无专门场景。图像和有限采样只帮助理解，不能替代数学证明。
- 自动中文释义靠**免费公共接口**（MyMemory，允许跨域、无需 key）：离线时只有内置 223 条词表可用，查不到的词会标「未查到」，联网后点「补全缺失的中文」即可重试。机器翻译可能不准（所以每一条都标了「词典／自动／自填」），点「释义」可以随时手改，手改的不会再被覆盖。
